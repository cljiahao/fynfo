# fynfo investment API (`/api/v1`)

Spec: `specs/security/204-investment-api.md`. This API is the only non-session machine interface
of fynfo (constitution 6.0.0, section 2.2). It serves the owner's tools (atlas, ballast, acciaux)
and never sees plaintext financial data: the summary is sealed to the caller, journal events are
sealed to fynfo.

All figures in this document are made up.

## Endpoints

| Method and path                             | Scope                         | Success                                                |
| ------------------------------------------- | ----------------------------- | ------------------------------------------------------ |
| `GET /api/v1/summary`                       | `summary:read`                | `200 {sealed, published_at}`                           |
| `GET /api/v1/journal/public-key`            | any `journal:append:*` scope  | `200 {v: 1, public_key}`                               |
| `POST /api/v1/journal`                      | `journal:append:<event_type>` | `201 {id}`                                             |
| `GET /api/v1/journal/meta[?since&since_id]` | `journal:meta`                | `200 [{id, caller, event_type, created_at}]` (no body) |

Other methods return `405`. Responses are JSON with `Cache-Control: no-store`. Machine-readable
schemas are in `docs/api/v1/*.schema.json`, generated from `src/lib/api-v1/schemas.ts`.

`POST /api/v1/journal` body: `{"event_type": "plan" | "sell_flag" | "verdict", "occurred_at":
<ISO 8601 with offset>, "sealed": <base64url envelope>}`. The key must hold the matching
`journal:append:<event_type>` scope. Maximum request body: 16 KB.

### Journal meta paging

`GET /api/v1/journal/meta` returns up to 500 rows ordered by `(created_at, id)`. To continue, send
the last row's values back: `?since=<created_at>&since_id=<id>`, URL-encoded and exactly as
returned (`created_at` keeps microseconds). Both parameters are required together. The response
headers `X-Next-Since` and `X-Next-Since-Id` carry the last row's cursor and are absent on an empty
page. Because the query string is part of the signed path, sign the encoded form you send.

## Authentication

Every request is signed with the caller's Ed25519 key. The server stores only the public key.

Headers:

- `Authorization: Fynfo-Ed25519 keyId=<uuid>`
- `X-Fynfo-Timestamp: <unix seconds>`
- `X-Fynfo-Signature: <base64 (standard, padded) Ed25519 signature of the canonical string>`

Canonical string (UTF-8, `\n` separators, no trailing newline):

```
fynfo-req-v1
<keyId, lower-case>
<timestamp>
<METHOD, upper-case>
<path with query string, exactly as sent>
<sha256 hex of the raw request body; of the empty string when there is none>
```

Sign and send an already-canonical path and query: percent-encoded, with no bare trailing `?`.
The server rebuilds the signed path from `URL.pathname` + `URL.search`, so any other spelling
fails verification.

The timestamp must be within 300 seconds of server time. Each signature can be used once; a
repeat is rejected as a replay.

## Sealed box (version 1)

Summary and journal payloads use the construction in the spec (X25519, HKDF-SHA256, AES-256-GCM).
The committed reference vector, which any implementation must reproduce and open, is in
`test/lib/sealed-box.test.ts` (constant `VECTOR`). The summary opens to
`{"surplus":1234.56,"weekly_budget":300,"currency":"SGD","as_of":"2026-11-27"}`.

## Python reference (`cryptography`)

```python
import base64, hashlib, json, os, time
import urllib.request
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.asymmetric.x25519 import (
    X25519PrivateKey, X25519PublicKey,
)
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from cryptography.hazmat.primitives.kdf.hkdf import HKDF

BASE = "https://<your fynfo host>"
INFO = b"fynfo-sealed-v1"


def b64u(data: bytes) -> str:
    return base64.urlsafe_b64encode(data).rstrip(b"=").decode()


def b64u_decode(text: str) -> bytes:
    return base64.urlsafe_b64decode(text + "=" * (-len(text) % 4))


def raw(public_key) -> bytes:
    return public_key.public_bytes(
        serialization.Encoding.Raw, serialization.PublicFormat.Raw
    )


def signed_request(signing_key: Ed25519PrivateKey, key_id: str, method: str,
                   path_with_query: str, body: bytes = b"") -> urllib.request.Request:
    timestamp = str(int(time.time()))
    canonical = "\n".join([
        "fynfo-req-v1", key_id.lower(), timestamp, method.upper(),
        path_with_query, hashlib.sha256(body).hexdigest(),
    ])
    signature = base64.b64encode(signing_key.sign(canonical.encode())).decode()
    request = urllib.request.Request(
        BASE + path_with_query, data=body or None, method=method.upper())
    request.add_header("Authorization", f"Fynfo-Ed25519 keyId={key_id}")
    request.add_header("X-Fynfo-Timestamp", timestamp)
    request.add_header("X-Fynfo-Signature", signature)
    if body:
        request.add_header("Content-Type", "application/json")
    return request


def open_sealed(recipient_private: X25519PrivateKey, envelope: str) -> bytes:
    parsed = json.loads(b64u_decode(envelope))
    if parsed["v"] != 1:
        raise ValueError("unsupported version")
    epk = b64u_decode(parsed["epk"])
    recipient_public = raw(recipient_private.public_key())
    shared = recipient_private.exchange(X25519PublicKey.from_public_bytes(epk))
    key = HKDF(hashes.SHA256(), 32, epk + recipient_public, INFO).derive(shared)
    return AESGCM(key).decrypt(
        b64u_decode(parsed["n"]), b64u_decode(parsed["ct"]),
        INFO + epk + recipient_public)


def seal(recipient_public: bytes, plaintext: bytes) -> str:
    ephemeral = X25519PrivateKey.generate()
    epk = raw(ephemeral.public_key())
    shared = ephemeral.exchange(X25519PublicKey.from_public_bytes(recipient_public))
    key = HKDF(hashes.SHA256(), 32, epk + recipient_public, INFO).derive(shared)
    nonce = os.urandom(12)
    ciphertext = AESGCM(key).encrypt(nonce, plaintext, INFO + epk + recipient_public)
    envelope = {"v": 1, "epk": b64u(epk), "n": b64u(nonce), "ct": b64u(ciphertext)}
    return b64u(json.dumps(envelope, separators=(",", ":")).encode())
```

## Errors

| Status | Body                                      | Meaning                                                                                                                                               |
| ------ | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 400    | `{"error":"invalid_request","issues":..}` | Body or query failed schema validation (only after successful authentication). `issues` is the flattened Zod error; no database text is ever returned |
| 401    | `{"error":"unauthorized"}`                | One identical response for a missing or malformed header, unknown, revoked or expired key, revoked caller, bad signature, stale timestamp or replay   |
| 403    | `{"error":"forbidden"}`                   | Authenticated, but the key lacks the scope (or the journal event type's scope)                                                                        |
| 404    | `{"error":"not_found"}`                   | Nothing published yet (summary) or no journal key (public-key)                                                                                        |
| 405    |                                           | Method not supported on the route                                                                                                                     |
| 413    | `{"error":"payload_too_large"}`           | Request body over 16 KB                                                                                                                               |
| 429    | `{"error":"rate_limited"}`                | 60 requests per minute per key; `Retry-After` is set                                                                                                  |
| 503    | `{"error":"unavailable"}`                 | A backing service failed; retry later                                                                                                                 |

Requests carrying a parseable key id are audited (caller when known, key id, endpoint, status, time);
requests with malformed auth headers are not. Oversized bodies (413) are rejected before headers are read and are not audited.
Bodies and signatures are never stored in the audit trail.

## Housekeeping

Expired nonce and audit rows are pruned opportunistically: about 1 in 100 requests calls the prune
function after responding, and a failure is logged and ignored. No cron configuration is needed.

## Vercel Firewall rules (apply in the Vercel dashboard)

The application limits each key, but unauthenticated floods should be stopped at the edge:

1. Rate limit: path starts with `/api/v1/`, 120 requests per minute per IP, action Deny (or
   Challenge is not suitable for machine clients).
2. Method allow-list: for path starts with `/api/v1/`, deny when the method is not `GET` or `POST`.
3. Optional: deny `/api/v1/` requests whose `Content-Length` exceeds 16384.
