# Fynfo roadmap — 2026-10-24

This replaces the open-item table in `2026-10-09-roadmap-progress.md`. That
file stays as the historical delivery log. The ranking follows the owner's
2026-10-23 direction: Fynfo is for Clarence and his household partner only,
and is never sold. Items rank by value to their own use. Public-user items
rank last.

Every item here is a proposal. Each one still needs its own spec, and for
migrations, crypto, dependencies or rulebooks, explicit owner approval before
implementation. The current audit remediation work is tracked in
`specs/audit/152-whole-repo-audit-2026-10.md`. It is not repeated here.

## Deprioritized — public-user items

- **R-retire (owner decision):** retire the marketing storefront, anonymous
  telemetry (`/api/track`) and the `/dashboard/admin` telemetry page. They
  exist for a public audience Fynfo will not have. Removing them deletes about
  26 tracked files, one API route, a service-role code path and the raw-palette
  colours (audit 152 T1/F2). It would also need a forward migration to drop
  the telemetry tables later. Until the owner decides, keep them as they are
  and spend no polish effort on them.
- Public signup and password recovery (draft 094).
- Billing, plans, ads and multi-tenant scale. These are rejected (monetization
  decision 2026-06-16; ads rejected for zero-knowledge reasons).
- "Default the last broker on new trades". This was dropped in 151 because it
  bypasses the DBS/FSMOne auto-CDP tick.
