# Fynfo roadmap — 2026-10-24

This is the single open roadmap. It supersedes the open items in
`docs/audit/2026-10-09-roadmap-progress.md` (kept as the delivery log),
`specs/feature/072-minimal-onboarding-and-roadmap.md` and
`specs/feature/081-sequential-delivery-roadmap.md`. Audit 152
(`specs/audit/152-whole-repo-audit-2026-10.md`) holds the evidence for the
P-codes below.

Fynfo is for Clarence and his household partner only and is never sold. Items
rank by value to that use.

## How phases work

- Each phase is one PR into `main` (or one tightly coupled PR set where noted),
  with full gates `pnpm check && pnpm test:ci && pnpm build` green and a local
  stack smoke test. It is merged and pushed before the next phase starts.
- Every item still needs its own spec, or a recorded batch in an audit record.
- Migrations, crypto, new dependencies and rulebooks need explicit owner
  approval. Production SQL is owner-run before the application PR merges.
- When a phase ships, tick its items here and close the spec.
